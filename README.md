# DocKit — แอปจัดการเอกสาร (PWA)

แอปมือถือสำหรับ **สแกนเอกสารจากรูปถ่าย · รวม/แยก/เรียงหน้า PDF · ลายน้ำ/คร่อมสำเนา · ลายเซ็น (e-signature) · ปกปิดข้อมูล · รูปติดบัตรและสำเนาบัตรพร้อมปริ๊น**
ทำงานในเบราว์เซอร์ 100% — **ไฟล์ไม่ถูกอัปโหลดไปไหน** ประมวลผลในเครื่องผู้ใช้ล้วน

---

## เปิดใช้งาน

**บนคอม:** ดับเบิลคลิก `serve.bat` **ใน File Explorer** (ไม่ใช่ปุ่ม Run ในแชท — คนละ network) จะเปิดเบราว์เซอร์ให้เอง
หน้าต่างดำจะพิมพ์ IP สำหรับเปิดบนมือถือในวง Wi-Fi เดียวกันด้วย

**บนมือถือให้เป็นแอปจริง:** ต้อง host โฟลเดอร์นี้บน **https** แล้ว
- iPhone (Safari): แชร์ → “เพิ่มไปยังโฮมสกรีน”
- Android (Chrome): เมนู ⋮ → “ติดตั้งแอป”

เปิดผ่าน LAN (`http://<ip>:8791`) ใช้ได้ครบทุกฟีเจอร์ แต่ติดตั้งลงหน้าโฮมไม่ได้ (PWA บังคับ https)

## หน้าจอ

| หน้า | ทำอะไร |
|---|---|
| **หน้าแรก** | ไทล์เครื่องมือ 8 ตัว + รายการหน้าล่าสุด |
| **เอกสาร** | นำเข้า (ถ่ายรูป/คลังรูป/PDF) · แตะเลือก · แตะสองครั้งเพื่อแต่งภาพ · กดค้างลากเรียงลำดับ · หมุน · ลบ |
| **แต่งภาพเอกสาร** | ตัดขอบอัตโนมัติ + ลาก 4 มุมเอง (ดัดภาพให้ตรงแบบ perspective) · โหมด ต้นฉบับ/เอกสารสี/เทา/ขาวดำ · สว่าง-คอนทราสต์ |
| **ลายน้ำ** | 3 โหมด: **ลายน้ำจาง** (ข้อความ ปูทั้งหน้า กันก็อป) · **คร่อมสำเนา** (“ใช้สำหรับ…เท่านั้น” หลายบรรทัด + เส้นขีดคร่อม ทึบอ่านชัด) · **รูป/โลโก้** · จัดวาง กลางหน้า/ปูทั้งหน้า/มุมล่าง/**วางเอง** (ลาก+ย่อขยายบนหน้าจริง) · ขนาด-ความจาง-องศา-สี · ทุกหน้าหรือเฉพาะหน้าที่เลือก |
| **ลายเซ็น** | วาดด้วยนิ้ว หรืออัปโหลดรูป (ตัดพื้นขาวออกให้) · บันทึกไว้ใช้ซ้ำ · ลาก/ย่อขยายวางบนหน้า · แนบวันที่ไทยได้ |
| **รูปติดบัตร** | ถ่าย/เลือกรูป · เปลี่ยนสีพื้นหลัง (ขาว/ฟ้า/แดง/เทา/โปร่งใส) · เลือกขนาดมาตรฐาน · จัดลงกระดาษ A4 หรือ 4×6 นิ้ว พร้อมเส้นตัด |
| **สำเนาบัตร** | ถ่ายด้านหน้า+ด้านหลัง → ตัดขอบบัตรอัตโนมัติ ดัดให้ตรง → วางบนแผ่นเดียวขนาดเท่าของจริง (ID-1 85.6 × 54 มม.) + คร่อม “ใช้สำหรับ…เท่านั้น” |
| **ปกปิดข้อมูล** | ลากกล่องดำทับข้อมูลที่ไม่อยากให้เห็น · หน้าที่มาจาก PDF จะถูกแปลงเป็นรูปให้อัตโนมัติ ข้อความข้างใต้จึงหายจริง |
| **ส่งออก** | ชื่อไฟล์ · A4 หรือตามขนาดรูป · คุณภาพ 3 ระดับ × ความละเอียด 3 ระดับ (ประหยัด/มาตรฐาน/ละเอียด) · ใส่เลขหน้า (“หน้า 1 จาก 9” หรือ “1 / 9”, ล่างกลาง/ล่างขวา) · ข้อความหัวกระดาษ · ทุกหน้าหรือเฉพาะที่เลือก (= แยกไฟล์) → หน้าจอ “เสร็จแล้ว” ให้บันทึก/แชร์ |

### ขนาดรูปติดบัตรที่มีให้

| ขนาดรูป | มม. | A4 | A5 | A3 | Letter | 4×6" | 5×7" | 6×8" | 8×10" |
|---|---|---|---|---|---|---|---|---|---|
| 1 นิ้ว | 25 × 32 | 56 | 21 | 112 | 49 | 12 | 18 | 28 | 42 |
| 1.5 นิ้ว / พาสปอร์ต | 35 × 45 | 28 | 12 | 56 | 28 | 6 | 9 | 15 | 25 |
| 2 นิ้ว | 40 × 50 | 20 | 9 | 45 | 20 | 4 | 6 | 9 | 16 |
| วีซ่าสหรัฐฯ | 50.8 × 50.8 | 15 | 6 | 35 | 12 | 2 | 6 | 6 | 12 |

บวก **กำหนดเอง** (กรอกกว้าง × สูง เป็นมิลลิเมตร) และ **รูปเดี่ยว** (ไฟล์เท่าขนาดรูปพอดี)

จำนวนคำนวณสดจาก `photoLayout()` และโชว์อยู่ข้างชื่อกระดาษแต่ละอันในแอป (เปลี่ยนขนาดรูปแล้วตัวเลขอัปเดตทันที)
แอปเลือกแนววาง (ตั้ง/นอน) ที่ใส่ได้มากกว่าให้อัตโนมัติ และบอกไว้ใต้ลิสต์
เพิ่มขนาดใหม่ = เติมแถวเดียวใน `PH_SIZES` / `PH_PAPERS` ใน `js/photo.js`

**ปริ๊นให้ได้ขนาดจริง:** ตอนสั่งพิมพ์ต้องเลือก **“ขนาดจริง / 100% / Actual size”** ห้ามใช้ “Fit to page” ไม่งั้นรูปจะย่อลงเล็กน้อยและขนาดเพี้ยน

## โครงไฟล์

```
Doc App/
  index.html                 โครงหน้า + icon sprite (SVG stroke ทั้งหมด)
  css/app.css                design token อยู่ใน :root หัวไฟล์ที่เดียว
  js/core.js                 state, นำเข้าไฟล์, หน้าแรก, grid, เลือก/เรียง/หมุน/ลบ
  js/scan.js                 ฟิลเตอร์ภาพ (flat-field + adaptive threshold), perspective warp, auto edge
  js/wm.js                   ลายน้ำ + ตัววาด overlay ลง canvas (พรีวิว/ธัมบ์)
  js/sign.js                 signature pad, ตัดพื้นขาว, โหมดวางลายเซ็น
  js/photo.js                รูปติดบัตร: ตัดพื้นหลัง, ครอบตามขนาด, จัดหน้ากระดาษ
  js/idcard.js               สำเนาบัตรหน้า-หลัง: ตัดขอบบัตร, วางลงแผ่นขนาดจริง
  js/redact.js               ปกปิดข้อมูล: ลากกล่องดำ + แปลงหน้า PDF เป็นรูป
  js/export.js               เขียน PDF ด้วย pdf-lib + หน้าจอ “เสร็จแล้ว”
  js/boot.js                 ผูก event ทั้งหมด
  sw.js  manifest.webmanifest  icons/     ส่วนที่ทำให้เป็น PWA
  vendor/                    pdf.js, pdf-lib, ฟอนต์ Sarabun (ไม่มี CDN — ออฟไลน์ได้จริง)
  serve.py / serve.bat       static server สำหรับทดสอบ
```

**ไม่มี build step** แก้ไฟล์แล้ว Ctrl+F5 เห็นผลทันที (service worker เป็น network-first สำหรับไฟล์แอป)
ถ้าแก้ไฟล์ใน `vendor/` หรือ `icons/` ต้องขยับเลข `V` ใน `sw.js` (พวกนี้ cache-first)

## ข้อควรรู้ทางเทคนิค

- **หน้าตาอยู่ที่ `:root` ใน `css/app.css` ที่เดียว** — สี/ระยะ/ความโค้ง เปลี่ยนธีมทั้งแอปได้จากบล็อกเดียว (ตอนนี้ตาม design draft (ชื่อไฟล์ draft คือ “Docket”): teal เข้ม `oklch(0.34 0.1 190)` + accent ฟ้าน้ำทะเล พื้นครีม)
- **เลือกหน้าได้จากในเครื่องมือเลย** — ลายน้ำ/ลายเซ็น/ส่งออก มีแถบรูปย่อของทุกหน้าให้แตะเลือก (`renderPickers()` ใน `core.js`) ใช้ `App.sel` ชุดเดียวกับแท็บเอกสาร เลือกที่ไหนก็เห็นตรงกันทุกที่
- **เปิดเครื่องมือตอนยังไม่มีไฟล์** จะเด้งแผ่น “เลือกไฟล์” (`#needFiles`) ให้นำเข้าได้จากตรงนั้น ไม่ต้องถอยกลับไปแท็บเอกสาร
- **การปกปิดข้อมูลเป็นการลบจริง ไม่ใช่แค่วางกล่องทับ** — กล่องดำบน PDF ไม่ได้ลบตัวอักษรข้างใต้ (คนรับ copy ออกไปได้) แอปจึง rasterize หน้านั้นเป็นรูปก่อนเสมอ (`flattenPage()` ใน `redact.js`) แลกกับการที่หน้านั้นจะค้นหาข้อความไม่ได้อีก
- **overlay เป็น non-destructive** — ลายน้ำ/ลายเซ็นเก็บเป็นพิกัด normalized (0..1) ต่อหน้า ยังไม่เผาลงไฟล์จนกดส่งออก
- **โหมด “วางเอง” แปลงทุกชนิดเป็นรูปก่อน** (ข้อความ → PNG ผ่าน text shaper ของเบราว์เซอร์) แล้วเก็บเป็น x/y/w/h เหมือน overlay ลายเซ็น จึงใช้ตัวลาก/ย่อขยายตัวเดียวกันได้ทั้งลายเซ็น ลายน้ำ และตราคร่อม (`openPlacement()` ใน `sign.js` รับ `pick(p)` เป็นตัวเลือกว่ากล่องจับ overlay ไหน) · การหมุนคิดรอบจุดกึ่งกลางกล่องทั้งฝั่ง canvas และฝั่ง PDF
- **ลายน้ำจางกับตราคร่อมสำเนาอยู่คนละ `slot`** จึงใส่ทับกันบนหน้าเดียวกันได้ และปุ่มลบจะลบเฉพาะโหมดที่เปิดอยู่ · ตราคร่อมถูก render เป็น PNG ทีเดียวทั้งบล็อก (หลายบรรทัด + เส้นขีด) แล้วส่งเข้าทางเดียวกับลายน้ำรูป — ได้การจัดวาง/หมุน/ส่งออกชุดเดิมทั้งหมด
- **ข้อความในลายน้ำ/วันที่ วาดเป็นรูป ไม่ใช่ text ใน PDF** — pdf-lib วางกลิฟตาม advance width ไม่ทำ GPOS ทำให้สระ/วรรณยุกต์ไทยซ้อนเพี้ยน (ที่ ป้ ปิ๊) จึง render ผ่าน text shaper ของเบราว์เซอร์แล้วฝังเป็น PNG · ข้อความเดิมในไฟล์ PDF ที่นำเข้ายังค้นหา/copy ได้ปกติ
- **ตัดพื้นหลังรูปติดบัตรเป็น flood fill จากขอบภาพ ไม่ใช่ AI segmentation** — ได้ผลดีกับฉากพื้นเรียบสีเดียว ถ้าฉากรกหรือเสื้อสีใกล้ผนังจะตัดไม่เนียน ผู้ใช้ปิดสวิตช์ได้แล้วรูปจะไม่ถูกแตะ (ถ้าจะเอาระดับตัดผมรายเส้นต้องฝังโมเดล segmentation เพิ่ม ~2-5 MB)
- **รูปนำเข้าถูกย่อเหลือด้านยาว 2400px** กันหน่วยความจำแตกบนมือถือ · เก็บเป็น Blob ถอดรหัสตอนใช้
- **หน้าจาก PDF ไม่ถูก rasterize** — ส่งออกด้วย `copyPages` ข้อความ/เวกเตอร์ยังคมและค้นหาได้ (ยกเว้นหน้าที่สั่งปกปิดข้อมูล ซึ่งตั้งใจให้กลายเป็นรูป)
- การหมุนหน้า PDF ใช้ `/Rotate` แล้ว map พิกัด overlay กลับเข้าสเปซหน้าเดิม (`toPage()` ใน `export.js`)
- **แท็บที่ถูกซ่อนจะทำให้ pdf.js หยุด render** เพราะมันใช้ requestAnimationFrame — สลับแอปกลางคันตอนนำเข้า PDF จะค้างจนกลับมา (โค้ดส่วนอื่นเลี่ยง rAF แล้ว)

## สถานะการทดสอบ (24 ส.ค. 2026)

ทดสอบ end-to-end ผ่าน DOM จริงในเบราว์เซอร์:

- นำเข้ารูป 2 + PDF 3 หน้า (ตั้ง/นอนปนกัน) → 5 หน้า ขนาดถูก
- ตัดขอบอัตโนมัติ: 1000×1400 → 833×1179 (พิกเซลมืด 30% → 3.2%)
- โหมดเอกสารสี: พื้นขาว 43.9% → 87.1% · ขาวดำคม: 95.2%
- เรียงใหม่ + หมุน 90° + ลายน้ำเฉพาะหน้าที่เลือก → PDF ที่ออกมาลำดับ/`/Rotate` ตรง, overlay ทุกตัวอยู่ในกรอบหน้า
- PDF เอกสาร: 15 image draw ต่อหน้า (ภาพ + ลายน้ำ 12 จุด + ลายเซ็น + วันที่)
- รูปติดบัตร: เปลี่ยนพื้นหลังแล้วมุมภาพเป็นสีที่เลือกเป๊ะ (255,255,255 / 59,111,214) ใบหน้าไม่ถูกแตะ · ปิดสวิตช์แล้วได้สีผนังเดิม (216,216,214)
- ไฟล์ปริ๊น: A4 = 297×210 มม. 28 รูป + เส้นตัด 28 เส้น · 4×6 นิ้ว = 102×152 มม. 4 รูป · รูปเดี่ยว = 25×32 มม. 1 รูป
- สำเนาบัตร: ตัดขอบบัตรจากรูปถ่ายอัตโนมัติได้ → ดัดเป็น 1011×638 px (85.6 × 54 มม. ที่ 300dpi) · ไฟล์ออกมา A4 210×297 มม. มี 3 ภาพ (หน้า + หลัง + ตราคร่อม)
- ปกปิดข้อมูล: ลากกล่องบนหน้าที่มาจาก PDF → หน้าเปลี่ยนเป็นรูปอัตโนมัติ → **ข้อความในไฟล์ที่ส่งออกถูกดึงออกมาได้ = “(ไม่มีข้อความ)”** ยืนยันว่าข้อมูลหายจริง
- ส่งออก: เปิดเลขหน้า + หัวกระดาษ + ความละเอียดประหยัด → PDF มีภาพหน้า 1 + ป้ายล่าง 1 + ป้ายบน 1 และกล่องดำ 1 กล่อง ขนาดไฟล์ 40 KB
